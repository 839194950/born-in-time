# 生逢其时

只抽出生年份的人生模拟网页游戏。地点固定为中国、普通家庭，抽到哪一年，就过哪一年的人生。

- 完整规格：`生逢其时-完整规格.md`
- **实现偏离规格清单：`docs/实现偏离规格清单.md`（先看这个，避免把有意改动当成 bug）**
- 实现计划：`docs/superpowers/plans/2026-10-21-life-sim.md`
- 史实核对表：`docs/史实核对表.md`
- 上线检查单：`docs/上线检查单.md`

## 本地开发

```bash

npm run dev        # http://localhost:5173
npm test           # 单元测试（引擎 + 数据 + 组件渲染）

npm run preview    # 本地预览构建产物
npm run fact-table # 从事件数据重新生成史实核对表
```

## 部署

纯静态站、零后端，构建产物在 `dist/`。

**线上地址（2026-10-24 起）**：https://born-in-time.pages.dev/ —— Cloudflare Pages 项目
`born-in-time`，连 GitHub 仓库 `main` 分支自动部署（构建 `npm run build`、输出 `dist`、
框架预设 None/自定义，无环境变量）。推上 `main` 即自动重新部署。

其他平台也可照此配置：Framework Preset 选 Vite，Build Command `npm run build`，Output Directory `dist`。

存档与前世纪录只用浏览器 localStorage，不依赖任何后端服务。

## 代码结构

```
src/engine/   与框架无关的纯 TS：时间推进、数值结算、窗口判定、账本、命型判定、存档
src/data/     全部内容：人口表、姓名库、事件（时代/阶段/条件/播报）、称号、道具年代表
src/ui/       界面：抽选屏、主循环屏、事件弹窗、结局卡、复盘页、像素渲染
tests/        与 src 同构；引擎可在 Node 里无 UI 跑完一整局
```

- 引擎不碰 DOM，所有随机都走种子随机（`mulberry32`），所以**存档 = 种子 + 事实流水**，恢复时重放得到完全一致的一生。
- 事件全部是配置对象；新增内容只改 `src/data/`，`validateCatalog()` 会拒绝没有出处的条目。

## 加一个事件

在 `src/data/events/{era,stage,conditional}.ts` 里加一条，字段见 `src/engine/types.ts` 的 `EventDef`：

```ts
{
  id: 'era_something_2010',
  layer: 'era',
  trigger: { type: 'year', year: 2010 },
  windowAge: [20, 40],
  title: '标题',
  body: '主干文案',
  variants: { rural: '只换一两句' },
  choices: [{ id: 'a', label: '选项', effects: { ability: 3, wealth: -1 }, outcome: '结果' }],
  ledgerWeight: 3,
  source: '出处（必须有）',
}
```

跑 `npm test` 会自动校验：id 唯一、有出处、有选项、窗口合法、效果幅度合规、2026 年后必须标“推演”。

四批优化，细节见 `docs/实现偏离规格清单.md` 第十二节。要点：

- **分享**：一局 = 一个种子，链接 `?s=<base36>`；结局卡页脚带二维码（白板 246）。
- **音频**：零素材，8 个 cue 全部 Web Audio 合成；死亡时刻先静默 1.2s 再「关机」。

- **新增**：身份证卡（深红标签 + 像素头像 + 信息表 + 哈希串）、背景卡（同年位次 / 家境 / 城镇化 / 预期寿命）、

## 已知取舍

- 城镇化率用 1977–2002 逐年精确值，不再插值；2000 年那道跳升是第五次全国人口普查的口径调整，出生卡上会说明。
- 1992 下海潮、1998 下岗潮、1998 福利分房按核验表归到**父母线**（`cond_parent_*`），不做成玩家本人窗口——1998 年玩家最大 21 岁，排不上分房的队。
- 非典（2003）与疫情（2020）按核验表降为背景播报，不占用玩家的抉择名额。
- 「每次都差一年的人」用**比例判据**：差一年 ≥4 次且占"够到的窗口"≥40%（规格写 3 次）。
  **真正的修法不是抬阈值**：先收窄"差一年"的带宽（`window.ts` 的 `edgeYears` 3 → 2）把命中率从 24.8% 压到 6.7%；
  那一轮之后"同年撞车不再丢弃"让账本条数变多，绝对阈值又失真（≥5 次回到 11.3%），
  所以改成比例——绝对次数不说明"每一次"，够到的门里四成以上是差一点关上的才算。实测 6.8%。
- 「比同龄人多活十年的人」阈值回到规格原文 `队列预期寿命 + 10`（v1 曾降到 +1.5 迁就分布，
  结果既让称号名撒谎、又仍是 0%；正解是打开分布上尾，让长寿成为可经营的 build）。
- 角色、场景与证件照是 AI 生成图（v4，见下），不是手绘 PNG；程序化像素绘制只作缺图兜底。
  要换回纯程序绘制或换美术风格，改 `src/ui/components/SceneStage.tsx` 与 `src/ui/lib/scene.ts`，
  并重跑 `assets-src/build_assets.py`。
- 年度重心的效果按 0.4 折算后生效，按钮上显示的是折算后的真实值——否则连年选“拼事业”会把数值推到 0。
- 灵感来源：1in8b.life。本作的主题、机制、文案、数据均为原创，未使用原作素材。


## 分享链接怎么用

开局「就这一年，开始」会把这一局的种子写进地址栏：

```
https://<你的域名>/?s=<base36>
```

把这个地址发出去，对方打开就是你抽到的那一年、那一个家庭、同一条人生。
结局卡页脚的二维码指向同一地址。

## 音频

默认开启，音量 0.35，可在时间控制条最右端关闭。

- 全部是 Web Audio 合成，**没有任何音频文件**（构建产物里没有 mp3/wav）。
- 抽签滚动的那个音在第一局是静音的——滚动在页面加载时自动开始，浏览器不允许此时启动
  音频上下文。第一个声音一定出现在你按下「就这一年，开始」之后。这是预期行为，不是 bug。
- 死亡时刻先整屏静默 1.2 秒，再给一声"关机"，不配乐、不上弦乐。

## v5（2026-10-24，修 bug 与补齐 1958–1976）

这一轮不是加功能，是修**会毁掉一局**的东西，外加把生年下限那段空白补上。

### 三个 P0

- **存档重放不还原「年度重心」→ 刷新后存档被判失效并删档。**
  `restoreGame()` 读了 `save.focusId` 却从没调用过 `setFocus()`，重放全程用每阶段默认重心，
  数值必然对不上 → 判 stale → `App.tsx` 直接 `clearCurrent()`。
  只要关闭时重心不是每阶段第一个选项就必现。
  现在重心变更进流水（`focusLog`，记的是**生效年份**，因为 tick 先 `year += 1` 再结算），
  存档另存 `phase` 与 `pendingEventId`，重放才能知道"这一年剩下的弹窗该补到哪一步"。
  实测 120 局随机切重心 + 随机存档点：恢复 120/120。
- **「再抽一年」抽到的还是同一年。** 地址栏的 `?s=` 从不清除，`reset()` 回出生屏时又拿它初始化种子。
  现在 `reset()` 会先清种子。
- **1958/1959 年生的人在 1976 年参加高考。** `stage_gaokao` 只有 `age: 18`，没有年份闸门，
  于是 1976 年考一次（恢复高考是 1977 年 12 月）、1977 年又"赶上恢复高考"。
  新增 `EventDef.yearRange`，高考限定 `[1977, 9999]` 且上过本科不再重考。

### 顺带查出来的两个更深的洞

- **`Game` 的随机流消耗取决于「出生是抽出来的还是传进来的」。**
  `new Game({ seed })` 会先抽一次出生再抽家人；`new Game({ seed, birth })` 直接抽家人。
  同一个种子，两条命——而存档重放走的正是后者。现在传入 birth 时也照样把 `rollBirth` 消耗掉。
- **存档停在"同一年第二个弹窗"上时重放会错位。** 只按年份边界停，会停在当年第一个弹窗。
  靠 `pendingEventId` 才补得准。

### 平衡

- 「差一年」带宽 3 年 → 2 年（`window.ts`），并且**窗口判定改成按整年**：
  旧实现按"事件年中 vs 生日"算月龄，12 月出生的人每个窗口都差半年，
  nearMiss 占 19.0% 而 1 月出生只有 14.3%。现在 1/6/12 月都是 5.0%，极差 0pp。
- 称号：`守一座城` 降为常见命型（rarity 3，排到「过小日子」之后）；`高开低走` 阈值 52 → 60（原来 0.2%，几乎不可达）。
- 学历补「专科」档：`junior_college` 之前不设任何 flag，专科毕业生在职业推导里等同没上过大学；
  21 岁的「毕业去向」也不再对没上大学的人触发（之前约四成玩家会读到"宿舍里的人都在讨论去哪"）。
- 工资锚点补到 2023 实测值 + 2050 推演值：之前停在 2020，2050 年还在显示 2020 年的月薪。

### 内容：1958–1976

- 3 条童年抉择（家庭视角，不做成"你的人生抉择"——那时候玩家还是孩子）：
  1960 粮本上的数字 / 1968 哥哥姐姐要走了 / 1970 推荐上大学。
- 6 条年代播报：1958 人民公社、1961 食堂散了、1963 学雷锋、1966 学校停课、1970 天上的《东方红》、1976 唐山地震。
- 出生那一年也要过一遍播报：`tick()` 是先 `year += 1` 再结算的，出生年永远轮不到，
  1958 年生的人看不到「人民公社」，1966 年生的看不到「学校停课」。
- 每条都写了 `source`，`npm run fact-table` 生成 99 行核对表（ok 59 / mech 33 / proj 7），无未建档条目。

### 体验与工程

- 默认倍速 1× → 2×（第一个弹窗从 6 分钟缩到 3 分钟）。

  置灰选项从 `tabindex="-1"` 改回可聚焦——"看得见但选不了"是设计意图，键盘用户不该连原因都听不到。
- 对照组（三条完整人生）从主循环首帧移到开局手势里预热，避免卡场景首帧。
- `CollectionBlock` 的 localStorage 写入从 render 期移到 effect（StrictMode 下会吞掉"新点亮"提示）。
- 删掉死代码：`availableChoiceIds` / `syncUrlWithSeed` / `happinessBand`。

## v7（2026-10-25，内容扩充：把窄带铺成年龄矩阵）

这一轮不是加事件，是改内容的**分布**。改前 1988 年以后出生的人 0–17 岁
**一条时代抉择都没有**，60 岁以后**全批次 0 条**——48 个生年 × 0–66 岁
三千多个人年里，68.5% 既没有时代抉择也没有播报。按题材看是房子 8 条、
加密货币 6 条、AI 4 条，童年 0、晚年 0：那是投资模拟器的结构。

### 两条抉择通道

`findDueEvents` 只按 `ledgerWeight` 排，era 权重 4–6 压过 stage 的 2–4，
人生节点永远排在时代事件后面（v6"结婚被房改挤掉"就是这个排序的产物）。
现在按 `channelOf()` 分两条：

- `life`（stage + 按年龄触发的 conditional）—— 不限条数，超出顺延，**永不降级**
- `era`（era + 按年份触发的 conditional）—— 每年最多 2 条，超出降级为一行播报

设 2 而不是 1：1998 年「房改 + 下岗」同年到期，只留一条等于让人错过一生的转折。
实测真正被降级的只有 0.02 条/局。

币圈从 6 条弹窗降到 3 条（2013 买 / 2020 峰值 / 2022 崩盘），其余退回播报。

### 生活切面不进账本

新内容都是 `layer: 'era'`，按原逻辑会进账本，实测把 `caught` 从 8.0 顶到 9.3，

"这件事是时代，但不是时代窗口。"
