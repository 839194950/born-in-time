# 生逢其时

只抽出生年份的人生模拟网页游戏。地点固定为中国、普通家庭，抽到哪一年，就过哪一年的人生。

- 完整规格：`生逢其时-完整规格.md`
- **实现偏离规格清单：`docs/实现偏离规格清单.md`（先看这个，避免把有意改动当成 bug）**
- 实现计划：`docs/superpowers/plans/2026-10-21-life-sim.md`
- 史实核对表：`docs/史实核对表.md`
- 上线检查单：`docs/上线检查单.md`

## 本地开发

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 单元测试（引擎 + 数据 + 组件渲染）
npm run build      # 类型检查 + 产出 dist/
npm run preview    # 本地预览构建产物
npm run fact-table # 从事件数据重新生成史实核对表
```

## 部署

纯静态站、零后端，构建产物在 `dist/`。

**Vercel**：导入仓库，Framework Preset 选 Vite，Build Command `npm run build`，Output Directory `dist`。

**Cloudflare Pages**：连仓库，Framework preset 选 Vite，Build command `npm run build`，Build output directory `dist`。

存档与前世纪录只用浏览器 localStorage，不依赖任何后端服务。

## 代码结构

```
src/engine/   与框架无关的纯 TS：时间推进、数值结算、窗口判定、账本、命型判定、存档
src/data/     全部内容：人口表、姓名库、事件（时代/阶段/条件/播报）、称号、道具年代表
src/ui/       界面：抽选屏、主循环屏、事件弹窗、结局卡、复盘页、像素渲染
tests/        与 src 同构；引擎可在 Node 里无 UI 跑完一整局
```

- 引擎不碰 DOM，所有随机都走种子随机（`mulberry32`），所以**存档 = 种子 + 事实流水**，恢复时重放得到完全一致的一生。
- 事件全部是配置对象；新增内容只改 `src/data/`，`validateCatalog()` 会拒绝没有出处的条目。

## 加一个事件

在 `src/data/events/{era,stage,conditional}.ts` 里加一条，字段见 `src/engine/types.ts` 的 `EventDef`：

```ts
{
  id: 'era_something_2010',
  layer: 'era',
  trigger: { type: 'year', year: 2010 },
  windowAge: [20, 40],
  title: '标题',
  body: '主干文案',
  variants: { rural: '只换一两句' },
  choices: [{ id: 'a', label: '选项', effects: { ability: 3, wealth: -1 }, outcome: '结果' }],
  ledgerWeight: 3,
  source: '出处（必须有）',
}
```

跑 `npm test` 会自动校验：id 唯一、有出处、有选项、窗口合法、效果幅度合规、2026 年后必须标“推演”。

## 数据来源

- `era-timeline-v1.md`：时代事件与二级随机参数的核验表，城镇化率、工资锚点、事件窗口以它为准。
- 生年范围已扩宽到 **1958–2005**（规格原文 1977–2002），抽签权重取出生人口数的平方根以压平峰谷。
- `docs/史实核对表.md`：由 `npm run fact-table` 从事件数据生成，逐条核对用。

## v2（2026-10-22）改了什么

四批优化，细节见 `docs/实现偏离规格清单.md` 第十二节。要点：

- **视觉**：暗炭底 → 暖纸底（米白纸、白卡、砖红强调、高饱和像素）；场景统一 3px 像素网格；
  角色 chibi + 1px 描边；桌面 ≥1024px 双栏。
- **节奏**：一局抉择 52 → 24（`EventDef.priority` 决定"弹窗"还是"一行播报"）。
- **数值**：健康衰减减半 + `healthBand` 回血 + 55 岁后能力/亲情折旧 + 长寿尾，
  12 个称号全部可达（「多活十年」需要主动养生，属可经营的 build）。
- **存档**：`SAVE_VERSION = 2` + 事件目录指纹；旧档判 `stale` 并明确提示，不再静默吞掉。
- **分享**：一局 = 一个种子，链接 `?s=<base36>`；结局卡页脚带二维码（白板 246）。
- **音频**：零素材，8 个 cue 全部 Web Audio 合成；死亡时刻先静默 1.2s 再「关机」。
- **留存**：际遇图鉴（跨局点亮时代窗口）；最小埋点 8 个事件，零后端。

### v2.1（同日，第二轮）

- **史实核对完成**：90 条逐条上网核对到官方来源，核对结论固化在 `scripts/gen-fact-table.ts` 的
  `VERIFIED` 表里（重跑 `npm run fact-table` 不会丢）。查出并修正 4 处事实错误
  （2017 一线房价的方向写反了、2015 股灾时长、2013 比特币价位、2014 二维码铺开的时点）。
  详见 `docs/史实核对表.md` 开头的「核对中查出来的问题」。
- **角色不再是贴纸**：表情与姿态随幸福/健康变化（`happiness >= 68` 弯眼微笑、`< 40` 眼睑下垂嘴角向下），
  上半身 1.1 秒一次的 1px 呼吸（`prefers-reduced-motion` 时静止）。
- **六个定格时刻有了场景底**：原来是不透明黑遮罩 + 白字，等于把最有情绪的六个瞬间做成幻灯片标题；
  现在是当下这一刻的场景做宽银幕横带，文字落在画面下方。
- **死亡屏是「慢慢没光」**：最后一帧在原地用 1.6 秒暗下去，字在 1.3 秒后才出现，与音频的「先静默」对齐。
- **弹窗内嵌五维读数**：移动端底部抽屉会盖住页面上的数值条，而玩家正要看它做选择，所以复制一行紧凑读数进弹窗。
- **门槛真的上线了**：`statMin` 提到当前分布的中位数附近，能见到置灰选项的局从 29.6% 升到 79.9%，
  每局约 1 次 —— 规格 §6.2「看得见但选不了」不再是个摆设。
- **结局卡幸福曲线纵轴自适应**：固定 20–90 会把一生都在 40–60 浮动的人画成直线。

### v3（2026-10-22，第三轮：界面语言重做）

用户拿 1in8b.life 的界面做参照，指出我们的页面"像塑料 AI"。复查后确认：**问题不在配色，
在版式结构**。v2 那套「暖纸 + 6px 厚白框 + 10px 圆角 + 阴影 + 大圆角按钮 + 彩色胶囊 + 34px 大标题」
即使换成另一套颜色也还是廉价——因为参考图的成本不在颜色上。

按参考图重做：

- **卡片**：1px 极浅边（#e7e7e3）+ 4px 圆角 + **几乎不投影**，正文 12px、标题 13px、元信息 11px 灰
- **顶部**：从"大年份 + 大圆角按钮"改成一根 **sticky 紧凑工具条**（左＝你是谁，右＝怎么放）
- **布局**：桌面从双栏改成 **三栏 252 / flex / 296**，左栏身份+状态、中栏场景+重心+纪录、右栏家人+同龄人+人生地图
- **新增**：身份证卡（深红标签 + 像素头像 + 信息表 + 哈希串）、背景卡（同年位次 / 家境 / 城镇化 / 预期寿命）、
  **人生地图**（一格一年，深红＝赶上、浅红＝差一年、灰阶深浅＝当年幸福）
- **像素场景**：远山改成蓝灰两层（原来和草地同色，像两片草地叠着）、人物整体放大（原来腿短到像跪着）、
  加了 **电线杆（带下垂弧度）** 和 **背景路人**，画面不再只有自家人
- **「今年的重心」加了处境说明**——光给四个按钮，玩家不知道选它有什么用
- **结局卡配色**跟页面统一（原来米黄+砖红，页面浅灰白+深红，并排放像两个产品）
- **出生屏**同样重做：巨大衬线年份 → 30px 小字；全宽大按钮 → 右对齐小方块；加了像素头像

顺带修掉两个真实缺陷：

- **定格画面（z-index 60）盖在事件弹窗（40）之上** —— 定格那 2.2 秒里玩家点不到任何东西。已把定格降到 35
- **置灰选项排在第一位** —— 玩家一进弹窗先看到的是点不动的按钮。现在能选的排前面

## 已知取舍

- 城镇化率用 1977–2002 逐年精确值，不再插值；2000 年那道跳升是第五次全国人口普查的口径调整，出生卡上会说明。
- 1992 下海潮、1998 下岗潮、1998 福利分房按核验表归到**父母线**（`cond_parent_*`），不做成玩家本人窗口——1998 年玩家最大 21 岁，排不上分房的队。
- 非典（2003）与疫情（2020）按核验表降为背景播报，不占用玩家的抉择名额。
- 「每次都差一年的人」阈值为 4 次（规格写 3 次）：窗口密度比规格假设时高，按 3 次会命中三成，最稀有的称号反而最常见。
- 「比同龄人多活十年的人」阈值按本模型实测校准为 `队列预期寿命 + 1.5`（模型上限约 +2.6），称号仍用规格原文。
- 角色与场景是 canvas 程序化像素绘制（零素材、调色板统一），不是手绘 PNG。要换手绘，只改 `src/ui/components/SceneStage.tsx` 与 `src/ui/lib/scene.ts`。
- 年度重心的效果按 0.4 折算后生效，按钮上显示的是折算后的真实值——否则连年选“拼事业”会把数值推到 0。
- 灵感来源：1in8b.life。本作的主题、机制、文案、数据均为原创，未使用原作素材。


## 分享链接怎么用

开局「就这一年，开始」会把这一局的种子写进地址栏：

```
https://<你的域名>/?s=<base36>
```

把这个地址发出去，对方打开就是你抽到的那一年、那一个家庭、同一条人生。
结局卡页脚的二维码指向同一地址。

## 音频

默认开启，音量 0.35，可在时间控制条最右端关闭。

- 全部是 Web Audio 合成，**没有任何音频文件**（构建产物里没有 mp3/wav）。
- 抽签滚动的那个音在第一局是静音的——滚动在页面加载时自动开始，浏览器不允许此时启动
  音频上下文。第一个声音一定出现在你按下「就这一年，开始」之后。这是预期行为，不是 bug。
- 死亡时刻先整屏静默 1.2 秒，再给一声"关机"，不配乐、不上弦乐。
