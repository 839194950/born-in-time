# 实现偏离规格清单

> **这份文件的作用**：下面每一条都是**有意为之的改动**，不是实现错误。
> 换会话、换人接手时，先看这里，再判断“是不是写错了”。
> 最后更新：2026-10-24

---

## 一、出生年份范围：1977–2002 → **1958–2005**

**改动来源**：用户实机试玩后提出「出生基本都集中在 1980–2000，内容太少，区间改大一点」。

**规格原文**：§0 第 2 条「出生年份范围：1977–2002（改革开放后；更早年代不做）」，并标注“不得变更”。
本次按用户明确要求覆盖该条。

**为什么选 1958 和 2005**：
- 1958 年出生的人在 1977 年 19 岁，正好撞上恢复高考——这是本作宣传语“从恢复高考那年开始抽”真正对应的那一批人。
- 1958–1975 年出生的人在 1990–1998 年正值壮年，能让「股市开市」「民工潮」「粮票作废」「包分配终结」「下岗」「房改」这些原本永远够不着的窗口真正可被赶上。
- 2005 年出生的人可以走到 2060 年代的推演段。

**连带改动**：
- `src/engine/types.ts` 的 `YEAR_FROM` / `YEAR_TO`
- `src/data/demography.ts` 补 1958–1976、2003–2005 的城镇化率、出生人口、预期寿命
- `src/data/names.ts` 补 1958–1976 姓名段（建国、卫东、桂兰、秀兰…），最后一段延长到 2005
- `src/data/yearNotes.ts` 补 1958–1976、2003–2005 的“这一年”

## 二、出生年份抽签权重：人口数 → 人口数的平方根

**原因**：直接按出生人口加权会让 1963（2950 万）和 1987（2550 万）形成两个尖峰，两头几乎抽不到，扩大范围也解决不了“老是那几个年份”。

**做法**：`yearWeight = Math.sqrt(出生人口数)`，峰谷比从 1.9 倍压到 1.35 倍。

**代价**：年份分布不再严格等于真实人口比例。规格 §3.1 说的是“量级加权”，仍属其许可范围。

## 三、称号判定阈值

| 称号 | 规格 | 实现 | 原因 |
|---|---|---|---|
| 每次都差一年的人 | 差一年 ≥3 次 | **≥4 次** | 事件窗口密度高于规格假设，按 3 次会命中三成，最稀有的称号反而最常见 |
| 比同龄人多活十年的人 | 享年 ≥ 队列预期寿命 +10 | **+10（已回到规格原文）** | v1 曾降到 +1.5 迁就分布，结果既让称号名撒谎、又仍是 0%。v2 改为打开分布上尾，这条偏离**作废** |
| 最后一班车的人 | 末班车型命中 ≥2 次 | **≥2 次，或 ≥1 次且赶上 ≥6 次** | 房改限定城镇后，单次命中已属少见；加了后半个条件避免它与“每次都差一年”抢同一批人 |

称号名称、稀有度顺序、判定优先级均未改动。

## 四、年度重心效果按 0.4 折算

**规格**：§5「每项效果为小幅（±1–3）」。数据里写的仍然是 ±1–3。
**实现**：每年实际生效值 = 数据值 × 0.4，**按钮上显示的是折算后的真实值**（因此会出现 `能力 +1.2` 这种小数）。

**原因**：重心是每年都结算的，连选 40 年“拼事业”，-2 × 40 = -80 会把人直接推到 0，后半生没有余地。

## 六、房改与包分配的「末班车」规则

- 房改（1998）加了 `conditions: { urban: true }`：福利分房只存在于城镇单位体系，农村玩家不该被算作“赶上末班车”。
- 父母单位分房（1997）设置的是 `family_home` 而不是 `has_home`：那是父母名下的房子，不该让玩家因此错过自己的人生第一套房。
- 包分配（1996）新增为独立事件，带 `lastTrain`，窗口 21–24 且需要上过大学。

## 七、条件专属事件不判定“路过”

`src/engine/game.ts`：`layer === 'conditional'` 的事件一律按 **赶上** 处理。
理由：条件专属是“你身上确实发生过的事”，不存在“路过”一说；`windowAge` 只用于核验表标注建议年龄。

---

## 八、死亡年龄算法

**规格 §4.1**：终点年龄 = 队列预期寿命 ±（健康终值映射修正 ±8）± 随机（±4）。
**实现**：死亡基准只在开局抽一次（队列预期寿命 ±4），健康修正每年按**当前健康**现算（±6），每年重判。

**原因**：若开局一次性算死，健康数值对寿命就没有任何影响，规格要的“健康修正寿命”会失效。

---

## 九、存档：重放而不是快照

存档只存 `种子 + 出生 + 已发生的事实流水`，恢复时用同一种子重放。
**原因**：避免“弹窗打开时刷新”导致事件丢失或重复结算。恢复后数值与账本必须与原局完全一致，不一致就当存档不可信丢弃。

---

## 十、美术：canvas 程序化像素绘制，不是 PNG 素材

角色与场景由 `src/ui/lib/pixel.ts` / `scene.ts` 在 canvas 上按 48×64 / 960×540 的像素格绘制，全局调色板约 34 色。
**原因**：48×64 网格上 AI 生成无法保证一致，程序化绘制能保证风格统一且零素材体积。
**换手绘的接口**：只改 `src/ui/components/SceneStage.tsx` 与 `src/ui/lib/scene.ts`，数据层不用动。

---

## 十一、其他小项

- 窗口判定取“年中”作为事件时点（6 月），因此“差 11 个月”这类文案可以逐月精确。
- 同一年最多弹一个抉择；判定为“路过”的事件不占名额，只写一行播报。
- 事件目录在测试里强制校验：id 唯一、必须有出处、必须有选项或标 broadcast、2026 年后必须写“推演”。

## 十二、v2 的改动（2026-10-22，四批优化）

这一批改动很大，逐条记下来，免得后来人当成 bug 改回去。

### 12.1 视觉：暗炭底 → 暖纸底
参照物是 1in8b.life。调色板整体重写（`src/ui/lib/pixel.ts`，约 50 色）；场景统一到 3px 像素网格
（960×540 = 320×180 个场景像素，与角色 scale 3 同密度）；角色改 chibi + 1px 暖褐描边；桌面 ≥1024px 双栏。

### 12.2 节奏：一局抉择 52 → 24（规格目标 20）
- `EventDef` 新增 `priority`：>= 3 才弹窗，< 3 只写一行播报。
- 24 个阶段事件只留 8 个弹窗，其余 16 个降级为播报。
- 日常小事：连续 ≥3 年无弹窗才补一件，一生上限 4 件。
- 反思节点 5 处 → 3 处（18/40/60）。

### 12.3 数值
- 健康衰减三档全部减半；新增 `healthBand` 与 `healthRecoverBoost`（低于上限时正向健康 ×2.2，且必须主动选）。
- 55 岁后能力 −0.5/年、亲情 −0.35/年。
- 长寿尾 `min(8, 养生年数 × 0.4)`，让「多活十年」成为可经营的 build。
- 财富阻尼：事件收益只在前 30% 时减半；年度漂移仍从 45 百分位起打折。

### 12.4 存档：版本 2 + 目录指纹
- `SAVE_VERSION = 2`、`SAVE_KEY = 'sfsq.current.v2'`（旧档留在原 key，不删）。
- `SaveV1.ch` 存事件目录指纹，对不上判 `stale` 并明确提示，而不是静默吞掉。
- `loadCurrentStatus()` 三态：ok / empty / stale（另有 corrupt）。

### 12.5 分享：一局 = 一个种子
v1 有两个互不相关的种子（出生一个、对局一个），「这一局」无法被任何标识指向。
现在出生也由同一颗种子推出，链接 `?s=<base36>`，结局卡页脚印二维码（白板 246）。

### 12.6 音频：零素材，全部 Web Audio 合成
8 个 cue，无音频文件；死亡时刻先静默 1.2s 再「关机」（守 §10-1）。
默认开、音量 0.35、独立静音开关。首个 cue 必定在「就这一年，开始」之后——抽签滚动没有手势，注定静音，这是预期不是缺陷。

### 12.7 新增：际遇图鉴与最小埋点
图鉴跨局累积「赶上过哪些时代窗口」；埋点 8 个事件、零后端，暴露到 `window.__SFSQ__`。

## 十三、v2.1 的改动（2026-10-22，第二轮）

### 13.1 史实：90 条全部核到官方来源

原先 82 条「待核」，其中还包括这一轮新增的 9 条。已逐条上网核对，结论写进
`scripts/gen-fact-table.ts` 的 `VERIFIED` 表（不是手改 Markdown，重跑不会丢）。

查出并修正的 4 处事实错误：

| 条目 | 原来 | 实际 |
|---|---|---|
| `era_tier1_house_2017` | 「一线房价再上一层」，暗示 2017 年还在暴涨 | 317 新政后 15 个热点城市环比**首次全面停涨**。改为「一线的门关上了」，选项换成「赶在关门前签」/「回老家买」 |
| `era_stock_crash_2015` | 「几周里跌去了大半」 | 5178→2850，**两个多月、44.95%**。改为「两个多月里跌去了四成多」 |
| `era_crypto_2013` | 「从几十美元涨到一千二，又跌回四百」 | 10 月底已 200–300 美元，高点约 1240，随后跌到 640。改为「从两百多美元涨到一千二，一个月后又跌回六百」 |
| `era_mobile_pay_2014` | 「年底街边的摊子开始贴二维码」 | 2014 年 3 月央行曾暂停二维码支付，大规模铺开在 2016 之后。改为「有些店里开始贴二维码」 |

### 13.2 角色：`happiness` 从「传进来没人读」变成真的影响表现

v1 把 `happiness` 一路传进 `drawCharacter`，函数体里一次都没用过，`is-happy` 还是个 CSS 里不存在的死类名。
现在：

- `happiness >= 68`：弯眼（眼尾上挑）+ 三段式上翘的嘴 + 更宽的腮红
- `happiness < 40`：眼睑下垂（只画下半）+ 嘴角向下，不画腮红
- 健康 < 30 时手垂得更低（`armDrop`）
- `breath: 0 | 1` 两帧呼吸，只动上半身，腿脚是站定的锚；1.1 秒交替一次；`prefers-reduced-motion` 时静止

### 13.3 定格画面：从全黑遮罩改成场景底

`.still` 原来是 `rgba(10,9,7,0.9)` 的全屏遮罩 + 三行白字。注释写的是「用场景底 + 排版做出停顿感」，
实现却连场景都没画。现在用当下这一刻的 `SceneStage`（`variant="plain"`）做一条宽银幕横带，
暖色暗角收边，文字落在画面下方。横屏场景塞进竖屏不 cover、只按宽度铺满，人始终完整。

### 13.4 死亡屏：先暗下去，再出字

最后一帧在原地用 1.6 秒淡到黑（`brightness 0.92 → 0.08`），文案延迟到 1.3 秒后才出现。
和音频方案的「进死亡屏先强制静默 1.2 秒」是同一个节奏。

### 13.5 弹窗内嵌五维读数

移动端弹窗是底部抽屉（约 46% 屏高），会把页面上的五维条盖掉一半——而玩家正要看它做选择。
现在弹窗内有一行紧凑读数（标签 + 值 + 3px 迷你条），配色沿用 `.stat-*`。

### 13.6 门槛：`statMin` 抬到分布中位数附近

v1 的 `ability: 40–55` 相对能力终值（P50 ≈ 70）形同虚设，只有 29.6% 的局能见到置灰选项。
现在 ability 35→46 / 40→52 / 45→58 / 50→62 / 55→68，wealth 35→42 / 40→48。
实测：见到置灰选项的局 **79.9%**，置灰选项占比 4.61%（每局约 1 次），12 个称号仍全部可达。

### 13.7 其他

- 墙上挂画改成「全家福 + 奖状」（原来是一小块草 + 两条灰线，手机上读不出是什么）
- 室外人物脚部下移到地平线之前（原来腿的下半截被栅栏切掉，人看起来像跪着）
- 结局卡幸福曲线纵轴按本局实际范围自适应

## 十四、v3 的改动（2026-10-22，第三轮：界面语言）

参照 1in8b.life 的界面重做版式。**结论记在这里，免得后来人以为「只是换了配色」**：

v2 的「暖纸底 + 6px 厚白框 + 10px 圆角 + 投影 + 大圆角按钮 + 彩色胶囊 + 34px 大标题」，
即使换成别的颜色也仍然会被读成"AI 味"。廉价感的来源是版式：圆角与描边太重、字号层级倒挂、
装饰元素太多、留白没有节奏。参考图的成本几乎全在版式上，不在颜色上。

### 14.1 版式规则（v3 覆盖层，写在 global.css 末尾）

| 维度 | v2 | v3 |
|---|---|---|
| 页面底 | 暖米色 #f6f0e4 | 中性浅灰 #f6f6f4 |
| 卡片 | 6px 厚白框 + 10px 圆角 + 阴影 | 1px #e7e7e3 + 4px 圆角 + 几乎无阴影 |
| 字号 | 正文 13-15px、标题 34px | 正文 12px、卡片标题 13px、元信息 11px |
| 顶部 | 大年份 + 一排大按钮 | sticky 工具条（44px），小方块按钮 26px 高 |
| 布局 | 双栏 | 三栏 252 / flex / 296（≥1180px） |
| 强调色 | 砖红 #a63b30 | 低饱和深红 #8c2f39 |
| 状态标签 | 彩色胶囊 | 灰底灰字小标签 |

### 14.2 新增的界面元素

- **身份证卡**：深红标签条 + 像素头像（复用 `drawCharacter`，`src/ui/components/Portrait.tsx`）+ 身份信息表 + 哈希串
- **背景卡**：同年位次 / 家境 / 出生时城镇化 / 同批人预期寿命
- **人生地图**：一格一年。深红＝赶上时代窗口，浅红＝差一年，灰阶深浅＝当年幸福
- **「今年的重心」的处境说明**（`stageHint(age)`）：告诉玩家当下是什么处境、选重心有什么用

### 14.3 像素场景升级

- 远山改成独立的蓝灰两档（`PALETTE.hillFar` / `hillFarDark`）——原来和草地同色，像两片草地叠在一起
- 人物整体放大（`STAGE_SCALE` 从 0.58–1.00 提到 0.72–1.22）——原来腿短到看着像跪着
- 加 **电线杆 + 下垂的电线**（`powerPole`）、**背景路人**（`bystander`）：院子不再只有自家人

### 14.4 顺带修掉的两个真实缺陷

1. **定格画面的 z-index（60）高于事件弹窗（40）** —— 定格那 2.2 秒里玩家点不到任何东西，
   自动化脚本也会因命中检测失败而一直等。已把 `.still` 降到 35，弹窗优先。
2. **置灰选项排在第一位** —— 玩家一进弹窗先看到的是点不动的按钮。门槛提高后（13.6）置灰项变多，
   这个问题被放大。现在能选的排前面、置灰的排后面。

### 14.5 结局卡

配色与页面统一（`INK #2b2b29` / `PAPER #f6f6f4` / `ACCENT #8c2f39`）——原来是米黄 + 砖红，
和浅灰白 + 深红的页面并排放像两个产品。

## 十六、移动端新增：年份进度条（2026-10-24，规格外新增）

规格没有"本年内进度"这个元素。主循环屏吸顶工具条下新增一行进度条：与 tick 同步、200ms 步进，
暂停或等抉择时冻结；一年时长 = `YEAR_MS / speed`（`YEAR_MS = 60000`）。同期修掉两处移动端显示问题
（倍速选中态被点按高亮洗白、身份证"生"印压住最后一行信息），均属 bug 修复、不记为偏离。
